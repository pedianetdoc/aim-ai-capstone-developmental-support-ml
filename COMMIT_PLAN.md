# Suggested Clean Commit History

To meet the rubric's "clean, professional commit history" criterion, do not upload everything as one anonymous drag-and-drop commit if you can avoid it.

A simple five-commit history is enough:

1. `Initialize capstone repository structure`
   - README.md
   - .gitignore
   - requirements.txt
   - empty data/models structure

2. `Add reproducible data and preprocessing pipeline`
   - src/config.py
   - src/data.py
   - src/preprocessing.py

3. `Add modeling evaluation and fairness utilities`
   - src/modeling.py
   - src/evaluation.py
   - src/fairness.py
   - src/explainability.py

4. `Add capstone notebooks and documentation`
   - notebooks/
   - docs/
   - reports/

5. `Add final presentation deliverables`
   - presentations/
